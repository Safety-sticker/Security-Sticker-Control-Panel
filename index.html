/** * Cloudflare Worker — حذف سجلات الأدمن الأقدم من 30 يومًا * يعمل تلقائيًا كل يوم الساعة 3 صباحًا بتوقيت UTC. */ export default { // Cron Trigger async scheduled(event, env, ctx) { ctx.waitUntil(cleanupOldLogs(env)); }, // مسار يدوي للاختبار async fetch(request, env) { const result = await cleanupOldLogs(env); return new Response(JSON.stringify(result), { headers: { "Content-Type": "application/json" } }); } }; async function cleanupOldLogs(env) { try { // الحصول على Firebase access token const accessToken = await getAccessToken(env); // حساب التاريخ (30 يوم مضت) const cutoff = new Date(Date.now() - 30 * 24 * 60 * 60 * 1000); // 1) الاستعلام عن السجلات القديمة (Firestore REST API) const queryUrl = `https://firestore.googleapis.com/v1/projects/${env.FB_PROJECT_ID}/databases/(default)/documents:runQuery`; const queryBody = { structuredQuery: { from: [{ collectionId: "adminLogs" }], where: { fieldFilter: { field: { fieldPath: "createdAt" }, op: "LESS_THAN", value: { timestampValue: cutoff.toISOString() } } }, limit: 500 } }; const res = await fetch(queryUrl, { method: "POST", headers: { "Authorization": `Bearer ${accessToken}`, "Content-Type": "application/json" }, body: JSON.stringify(queryBody) }); const data = await res.json(); if (!Array.isArray(data)) return { deleted: 0 }; const docs = data.filter(d => d.document).map(d => d.document.name); if (docs.length === 0) return { deleted: 0 }; // 2) حذف كل سجل let deleted = 0; for (const docName of docs) { const deleteRes = await fetch( `https://firestore.googleapis.com/v1/${docName}`, { method: "DELETE", headers: { "Authorization": `Bearer ${accessToken}` } } ); if (deleteRes.ok) deleted++; } return { deleted, total: docs.length }; } catch (err) { console.error("cleanup error:", err); return { error: err.message }; } } /** * الحصول على access token عبر JWT * يستخدم Service Account من Secrets */ async function getAccessToken(env) { const now = Math.floor(Date.now() / 1000); const header = { alg: "RS256", typ: "JWT" }; const payload = { iss: env.FB_CLIENT_EMAIL, scope: "https://www.googleapis.com/auth/datastore", aud: "https://oauth2.googleapis.com/token", iat: now, exp: now + 3600 }; const encodedHeader = base64UrlEncode(JSON.stringify(header)); const encodedPayload = base64UrlEncode(JSON.stringify(payload)); const unsignedToken = `${encodedHeader}.${encodedPayload}`; // توقيع JWT باستخدام crypto.subtle const privateKey = await importPrivateKey(env.FB_PRIVATE_KEY); const signature = await crypto.subtle.sign( "RSASSA-PKCS1-v1_5", privateKey, new TextEncoder().encode(unsignedToken) ); const encodedSignature = base64UrlEncode(signature); const jwt = `${unsignedToken}.${encodedSignature}`; // تبادل JWT بـ access token const tokenRes = await fetch("https://oauth2.googleapis.com/token", { method: "POST", headers: { "Content-Type": "application/x-www-form-urlencoded" }, body: new URLSearchParams({ grant_type: "urn:ietf:params:oauth:grant-type:jwt-bearer", assertion: jwt }) }); const tokenData = await tokenRes.json(); if (!tokenData.access_token) { throw new Error("Failed to get access token: " + JSON.stringify(tokenData)); } return tokenData.access_token; } async function importPrivateKey(pemKey) { const pemContents = pemKey .replace(/-----BEGIN PRIVATE KEY-----/, "") .replace(/-----END PRIVATE KEY-----/, "") .replace(/\\n/g, "") .replace(/\s/g, ""); const binaryDer = Uint8Array.from(atob(pemContents), c => c.charCodeAt(0)); return await crypto.subtle.importKey( "pkcs8", binaryDer.buffer, { name: "RSASSA-PKCS1-v1_5", hash: "SHA-256" }, false, ["sign"] ); } function base64UrlEncode(data) { let str; if (data instanceof ArrayBuffer) { str = btoa(String.fromCharCode(...new Uint8Array(data))); } else { str = btoa(data); } return str.replace(/\+/g, "-").replace(/\//g, "_").replace(/=+$/, ""); }
